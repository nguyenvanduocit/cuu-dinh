# Element Trial: Thuỷ

## Nhịp

Pháp trận thử thách Thuỷ element. Thuỷ linh lực chậm, nặng, nhưng tương sinh mạnh với Mộc. Player phải balance giữa Thuỷ route đến linh đan (tốt nếu đan Mộc, xấu nếu đan Hoả) và tránh tương khắc Thổ.

Không có Sư Phụ. Đệ tử tự rút ra bài học.

## NPC tương tác

Không có NPC hỗ trợ trong pháp trận này.
