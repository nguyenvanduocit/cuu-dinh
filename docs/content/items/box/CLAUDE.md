# Box (Hộp) — store + timed release (Tier 3)

> Tier 3 cho `items/box/`. Cascade từ root → Tier 1 → `items/CLAUDE.md` (Tier 2).

---

## Sub-type trong tu chân lore

Box = **hộp pháp** — hộp cổ chứa pháp bảo, đan dược, di vật. Trong tu chân lore = container có hồn pháp khí — nắp box thường khắc ấn triện cấm chế, chỉ mở được bằng khế ấn cụ thể (huyết, chú văn, ngộ đạo).

Một số box cổ chứa thiên kiếp năng lượng — mở ra = giải phóng power burst nguy hiểm.

---

## Game role specific

- **Physics**: **tích linh lực bên trong + release theo timed cycle / trigger**. Khác cauldron ở chỗ: cauldron sink-boil-release multi-step continuous; box = store stable + release burst định kỳ.
- **Anchor placement**: thường ở vị trí có anchor stable (corner / fixed).
- **Element bias**: rộng — variant theo nội dung box (Hoả essence box, Thuỷ qi box, ...).

---

## Design constraints

- Box MUST có **nắp visible** + **ấn triện trên nắp** trong art.
- Effect MUST có **store phase** rõ (charging) + **release burst** rõ — 2-phase signature.
- Nắp có thể **mở** trong art (visualize release moment) hoặc **đóng** (store phase).
- Closed silhouette ≠ generic chest — phải có khắc Hán-tự / hoa văn tu chân.

---

## Lore motifs

- Material: gỗ trầm hương, đồng cổ, kim loại tinh chế, đá thạch sa.
- Form: hộp vuông / chữ nhật / oval, có chân, có ấn triện khoá.
- Khoá: ấn triện chú văn (KHÔNG metal lock/key modern).

## Anti-patterns

- ❌ Box không có nắp visible → mất identity container.
- ❌ Effect release ngay (không có store phase) → sai 2-phase signature.
- ❌ Nắp khoá metal lock/key modern → phá tu chân.
- ❌ Silhouette generic chest (treasure chest fantasy) → mất identity tu chân.
- ❌ Nội dung box không match element bias variant (Hoả essence box mà release effect Thuỷ).
- ❌ Modern aesthetic (gloss, gradient flat, sci-fi metal) → phá craftsmanship.
