# Element treatment — Ngũ Hành

> Dệt vào prompt theo cột `element` của data, viết dạng cụm prose. Engine không cần hex — dùng tên màu
> (hex sống ở `palette.md` làm document intent).

| `element` (data) | Hán-Việt | Cụm prose dệt vào prompt |
|---|---|---|
| `metal` | Kim | `forged metal with a sharp angular silhouette and a cold metallic gleam, thin imperial-gold edge light` |
| `wood` | Mộc | `living wood with organic curves and sprouting leaf motifs, a soft jade-green qi glow` |
| `water` | Thuỷ | `flowing water forms with ripples and drifting mist, a deep-blue inner light` |
| `fire` | Hoả | `upward-licking flames and floating embers, radiant cinnabar-red heat` |
| `earth` | Thổ | `solid blocky weight with dust and carved stone, earthen-brown tones` |
| `void` | Vô Cực | `a cosmic void with star-flecks and an infinity motif, an ethereal twilight-purple aura` |

Khi cột `element` rỗng (affix/đan dược trung tính) → bỏ cụm này, dùng `neutral ivory-and-gold tones`.

## Tương sinh / tương khắc (cho hiệu ứng, không cho item tĩnh)
Cycle: Kim → Thuỷ → Mộc → Hoả → Thổ → Kim (`docs/ui-wireframes.md`).
