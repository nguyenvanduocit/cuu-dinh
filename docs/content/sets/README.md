# `sets/` — Set Bonuses

> 3 sets ship in v1.0.

## Design rationale

**Tu Linh** (4 items) activates a khi tran that pulls linh luc toward the board center. **Ngu Hanh** (5 items, 1 per element) enables elemental cycling that rewards the full Kim->Thuy->Moc->Hoa->Tho->Kim cycle with x3 intensity. **Thap Bat La Han** (18 items, endgame) is a hard set that grants linh dan resurrection 1x/phap tran — designed as a high-investment endgame puzzle rather than an early goal. Sets grow at 1/year to maintain set scarcity.

## Content scaling

v1.0: 3 sets. Live ops: +1/year.
