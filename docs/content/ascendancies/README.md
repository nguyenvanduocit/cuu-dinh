# `ascendancies/` — Dao Phai (Ascendancy Subclasses)

> 5 dao phai, unlock level 30 (decision #10).

## Design rationale

Each Dao Phai represents a distinct cultivation philosophy and alters gameplay significantly. Player chooses permanently at Act 4 Vo Cuc Dinh. The 5 paths map loosely to Ngu Hanh elemental affinities but are not element-locked — they're playstyle archetypes.

├── design.md   # required — subclass mechanics + node tree
