# Thân Bảo Đan Lư (`body-rare-furnace`)

## Lược tả

Thân Lò Bảo cấp: lò đan bảo cấp — board rộng rãi 11 anchor, intensity nền mạnh, thêm bonus loot drop cho mọi playstyle.

## Implicit

Board **900×1300px** — **11 anchor** linh khí — **+10% intensity nền** — **+5% loot drop rate** toàn pháp trận. Trần Thân §3: +15% foundation — Bảo chiếm 67% trần. Loot drop rate +5% cộng vào base pool; không specific element.

## Slot role

**Thân (Body)** = thân Lò, định nghĩa board size + intensity foundation + loot. Rare tier: board gần chuẩn endgame (900×1300), foundation +10% đủ để build chain medium không cần affix bù. +5% loot biến Thân thành slot đa năng — không cần hi sinh loot khi nâng intensity.

## Build use

**Workhorse tier** — dùng được mọi build T8-T13 mà không cần specialise. Board 900×1300 đủ để `sun-wukong-staff` (split ×3) phủ kín mà không chồng chain. Progression endgame: nâng lên `body-legendary-nine-turn` khi cần 13 anchor + modifier slot. Mọi Đạo Phái dùng được; không có anti-synergy.
