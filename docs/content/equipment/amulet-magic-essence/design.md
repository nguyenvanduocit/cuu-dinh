# Khắc Phù Linh Tinh (`amulet-magic-essence`)

## Lược tả

Khắc Phù Linh cấp: bùa tinh luyện hơn, đủ mạnh để đồng thời nâng cường độ lẫn mở kênh crit nhỏ.

## Implicit

**+10% intensity toàn cục** + **+5% crit chance** toàn cục. Trần Khắc Phù §3: +25% — Linh chiếm 40% trần intensity. Crit chance cộng vào crit base (§4); mỗi crit nhân intensity tại điểm va chạm.

## Slot role

**Khắc Phù (Amulet)** = nguồn intensity toàn cục duy nhất trong Lò 8-slot. Ceiling §3: +25% global. Magic tier mở thêm crit channel (+5%) — tạo cầu nối sang Rare/Legendary cho build crit-focused.

## Build use

Tier phổ thông mid-game. Khớp build **Hoả — Crit combo**: Đỉnh Linh Hoả (element bias Hoả) + Khắc Phù Linh Tinh (+5% crit) + prefix affix `Hung Diệt` → thackle crit early. Progression: upgrade lên `amulet-rare-great` khi crit chance muốn vượt 15%. Mọi Đạo Phái dùng được; Tử Vi (+10% crit free) hưởng lợi nhiều nhất từ crit stack này.
