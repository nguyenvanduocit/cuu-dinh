# Đỉnh Thần Vô Cực (`crown-legendary-void`)

## Lược tả

Đỉnh Lò Thần cấp: 3 linh lực mỗi 2 giây — nguyên tố ngẫu nhiên hoàn toàn đạt +50% bias trần §3, thêm 1 reroll spawn miễn phí mỗi ván.

## Implicit

**3 linh lực / 2s** — **element ngẫu nhiên mỗi ball** (mỗi ball tự chọn element độc lập) — **+50% element bias** cho element của từng ball tại thời điểm spawn (= trần §3 Đỉnh, tối đa) — **1× free reroll spawn pattern / ván** (đổi lại ngẫu nhiên set góc spawn). Trần Đỉnh §3: +50% — Thần chạm trần bias tối đa.

## Slot role

**Đỉnh (Crown)** = đỉnh Lò. Legendary tier: mỗi ball nhận trần bias §3 ngay khi spawn nhưng element là ngẫu nhiên → phủ đều mọi nguyên tố mỗi ván. Đây là Đỉnh của build **Ngũ Hành đa nguyên tố** — không commit vào 1 element mà chạy tất cả đồng thời.

## Build use

Thiết kế cho **Ngũ Hành 5-cycle** (decision #24 emergent composition): 3 ball ngẫu nhiên × +50% bias per-ball = ít nhất 1-2 nguyên tố tương sinh kích hoạt mỗi 2s. Kết hợp `amulet-legendary-heaven-fate` (cộng hưởng tương sinh +10% khi crit) = chain tương sinh liên tục. `base-magic-rescue` (50% ball recovery) cần thiết vì 3 ball/2s → nhiều ball rớt hơn. Đạo Phái Hỗn Nguyên (bonus khi ngẫu nhiên element trigger) là Đạo Phái thiết kế riêng cho Đỉnh này.
