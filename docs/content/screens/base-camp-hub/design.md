# Khai Lư Trấn Hub (`base-camp-hub`)

## Identity

Main hub screen. Mode-less navigation — player can reach any sub-screen from here. Shows base camp village with NPCs, top nav bar, bottom HUD with resources.

## Layout principles

- Top nav: Lò, Tree, Atlas, Sơn Hà, Stash, Vendor, Profile
- Central area: village scene with clickable NPCs (Sư Phụ, Lão Hồ Ly, Đan Lư Bàn, Đạo Sĩ Vô Danh, Lò Thần, Lão Bà Thiên Cơ, Sơn Hà Đồ Lệnh altar)
- Bottom HUD: Kim Đan, Linh Đan, Phong Ấn counts + Cấp Đạo Sĩ + quest hint
- Background: tiên phủ courtyard / đan thất painted scene (uses Khai Lư Trấn region art)
- NPCs: pixel sprites
