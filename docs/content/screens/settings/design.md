# Cài Đặt (`settings`)

## Identity

Settings screen. Accessible from main menu and base camp. Graphics, audio, language, tu chân options (veteran mode, difficulty), accessibility (colorblind, font scale, visual SFX cues, key remap).

## Layout principles

- Section groups: Đồ Hoạ, Âm Thanh, Ngôn Ngữ, Tu Chân, Accessibility
- Standard controls: dropdowns, checkboxes, sliders
- Save/Cancel buttons
- Background: reuse Stash texture + corner ornament motif
- Pure UI — minimal art needs
