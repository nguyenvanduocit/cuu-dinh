# Cài Đặt (`settings`)

## Identity

Settings screen. Accessible from main menu and base camp. Graphics, audio, language, tu chân options (veteran mode, difficulty), accessibility (colorblind, font scale, visual SFX cues, key remap).

## Layout principles

- Top status: brush-stroke title + back góc trái
- Content cuộn dọc: sections theo thứ tự Đồ Hoạ → Âm Thanh → Ngôn Ngữ → Tu Chân → Khả Năng Tiếp Cận
- Controls: slider kéo ngang (track 44px cao), toggle pill ON/OFF, selector row 56px → bottom sheet chọn option
- Bottom thumb-bar cố định: [Lưu] + [Huỷ] luôn trong tầm ngón cái, không cuộn mất
- Back góc trái / vuốt mép trái → về màn trước (không lưu)
- Background: reuse Stash texture + corner ornament motif
- Pure UI — minimal art needs
