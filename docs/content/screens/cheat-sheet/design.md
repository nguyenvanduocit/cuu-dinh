# Ngũ Hành Wheel (`cheat-sheet`)

## Identity

Always-visible overlay at bottom-right of all gameplay screens. Shows Ngũ Hành cycle, current linh đan element (highlighted), tương sinh element (green arrow), tương khắc element (red arrow). Not a full screen — a persistent HUD widget.

## Layout principles

- Compact Ngũ Hành wheel diagram (5 nodes with generating/overcoming arrows)
- Current linh đan element highlighted
- Tương sinh: green arrow
- Tương khắc: red arrow
- Always visible during pháp trận and setup
