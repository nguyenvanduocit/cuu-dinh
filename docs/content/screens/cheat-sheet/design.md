# Ngũ Hành Wheel (`cheat-sheet`)

## Identity

Ngũ Hành reference. Shows Ngũ Hành cycle, current linh đan element (highlighted), tương sinh element (green arrow), tương khắc element (red arrow). 3 mode: widget glanceable trong thumb-bar, bottom sheet on-demand, inline mini wheel trong card setup.

## Layout principles

3 mode tùy ngữ cảnh:
- **Widget [⊙]** (combat + atlas): icon màu ngũ hành active trong bottom thumb-bar, tap → sheet
- **Bottom Sheet**: wheel full + tương sinh/tương khắc label + damage multiplier; vuốt xuống đóng
- **Inline mini wheel** (setup screens): embed trong card linh đan, không cần sheet riêng
