# Sơn Hà Đồ (`atlas`)

## Identity

Atlas world map screen. T1-T16 pháp trận nodes arranged around Vô Cực center. 4 corner boss citadels. Hover node for Đan Pháp drop pool + difficulty. Click to fast-travel.

## Layout principles

- SVG node map (pan/zoom)
- Nodes: unlocked (●), locked (⚪), corner boss (citadel icon)
- Vô Cực center hub
- Bottom bar: player level, atlas progress, tier max
- Background: celestial map of floating regions with deep space between nodes
