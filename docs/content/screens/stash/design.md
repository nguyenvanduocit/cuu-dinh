# Kho Đồ (`stash`)

## Identity

Inventory/stash screen. Tabbed by item type: Đan Dược, Linh Khí, Đan Pháp, Nguyên Liệu, Cổ Vật, Lò Parts. Grid 2 cột cuộn dọc; tap item → bottom sheet detail (full số liệu + actions).

## Layout principles

- Top status: brush-stroke title trái, slot count (used/max) phải — glanceable
- Tab bar: 6 category tabs cuộn ngang, touch target ≥44px each
- Grid: 2-column icon grid cuộn dọc, hàng ≥56px, count badge góc phải mỗi icon
- Tap item → bottom sheet detail (full số liệu + action buttons)
- Bottom thumb-bar: action buttons [Dùng][Trang Bị] + nav tabs; cố định, không cuộn
- Back: góc trái top / vuốt mép trái
- Background: dark parchment-and-lacquer storage panel texture with faint lacquered seal texture
