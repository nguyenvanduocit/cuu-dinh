# Kho Đồ (`stash`)

## Identity

Inventory/stash screen. Tabbed by item type: Đan Dược, Linh Khí, Đan Pháp, Nguyên Liệu, Cổ Vật, Lò Parts. Grid display. Hover for tooltip, click to drag.

## Layout principles

- Tab bar: 6 category tabs
- Grid: icon grid with count badges
- Hover: effect tooltip
- Click: drag to use slot
- Bottom: total slots used / max
- Background: dark parchment-and-lacquer storage panel texture with faint trigram watermark
