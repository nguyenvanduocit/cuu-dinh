# Modal Cảnh Báo — Wireframe

Source: `docs/ui-wireframes.md` §14

### Confirmation modal (dangerous actions)

```
╔════════════════════════════════╗
║  ⚠ Áp Phong Ấn                 ║
║                                ║
║  Phong Ấn không thể undo.     ║
║                                ║
║  4 kết quả ngẫu nhiên:        ║
║  - 25% Phá Niêm (strip)       ║
║  - 25% Giáng Phẩm             ║
║  - 25% Thăng Phẩm             ║
║  - 25% Khắc Phong Ấn          ║
║                                ║
║  [Tiếp tục]  [Huỷ]              ║
╚════════════════════════════════╝
```

First-time: 3-second delay before [Tiếp tục] enabled. Subsequent: immediate.
