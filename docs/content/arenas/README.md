# `arenas/` — Boss Arenas

> 3 boss arena environments.

## Design rationale

Boss arenas are distinct environmental stages for major boss encounters. Each arena has unique visual and mechanical properties that interact with the boss's attack patterns.

## Entity layout

```
arenas/<id>/
├── design.md   # required — arena description, mechanics
└── prompt.md   # optional — environment concept art MJ prompt
```
