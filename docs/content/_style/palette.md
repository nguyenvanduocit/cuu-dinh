# Palette — Tiên Phủ Huyền Quang

> Nguồn: `docs/art-direction.md:27-60`. MJ v6 đọc **named color** tốt hơn hex — hex chỉ document intent.

## 6-color locked

| Named color | Hex | Vai trò |
|---|---|---|
| ink black | `#1A1A1A` | Mực huyền — background, base |
| cinnabar red | `#C82127` | Đỏ chu sa — primary accent, danger |
| imperial gold | `#D4AF37` | Vàng kim — highlight, success |
| ivory white | `#F5E6D3` | Trắng ngà — text, neutral |
| jade green | `#2E5E4E` | Xanh ngọc — Mộc element |
| twilight purple | `#4A1942` | Tím triều — Tâm Ma, dark energy |

## UI ratio
60% mực huyền nền · 30% đỏ chu sa frame · 10% vàng kim highlight (`art-direction.md:131-136`).
