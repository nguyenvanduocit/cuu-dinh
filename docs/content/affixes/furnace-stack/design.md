# Đan Lư Tinh (`furnace-stack`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | Mỗi 3 hit: +3% intensity stack tạm trong ván (max 5 stack) |
| T2 | Mỗi 3 hit: +4% intensity stack (max 6) |
| T3 | Mỗi 3 hit: +5% intensity stack (max 8); stack không mất cuối ván |

## Tương tác

Stack tích trong lớp **intensity multiplier** (§7.3) — mỗi stack là +3/4/5% flat intensity bonus thêm vào mỗi hit. Max cap 5/6/8 stack = +15/24/40% intensity tổng từ affix này. Stack reset cuối ván ở T1-T2; T3 stack persist: mang sang ván tiếp theo trong cùng pháp trận — sau 5-8 ván, T3 có thể đạt full 8 stack từ ván 2-3 và giữ nguyên đến boss. Đếm hit trên linh khí này (không phải hit vào linh đan).

## Build & Synergy

Roll trên mọi base type — suffix nên pair với prefix offensive. Giá trị tăng mạnh theo thời gian trong pháp trận: yếu ván đầu, mạnh nhất ở ván boss. Combo với `first-strike-lethal` (hit đầu ván boss đã có full stack): multiplier compound lớn. `kindred-generation` trên linh khí cùng element nhân intensity thêm trên nền stack. Đạo Phái bất kỳ — stack-based build phù hợp mọi element. Cổ vật **Đan Lư Càn Khôn** (+1 affix tier mỗi ván) synergy: nâng T2→T3 giữa run để mở persist.
