# Tam Sinh (`triple-birth`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | 12% chance nhân đôi linh lực khi va chạm |
| T2 | 16% chance nhân đôi linh lực khi va chạm |
| T3 | 20% chance nhân đôi linh lực khi va chạm |

## Tương tác

Nhân đôi tạo clone linh lực với đầy đủ `velocity_factor`, `charge_factor`, element và mọi affix buff đang active — clone áp damage formula riêng khi hit đan. Không giảm intensity gốc. Clone có thể kích hoạt proc từ affix khác (chain jump, pierce, crit). Giới hạn: clone không nhân đôi tiếp (tránh vô hạn). 20% chance T3 → kỳ vọng 1 clone mỗi 5 va chạm.

## Build & Synergy

Roll mọi base type (prefix, element-neutral). Giá trị nhân theo mọi multiplier đang stack — càng nhiều intensity buff, clone càng mạnh. Kết hợp `thunder-sound-frenzy` (all-hit event với linh lực đôi → damage tổng nhân đôi) và `victory-stack` (stack intensity tăng dần, clone hưởng đủ stack). Đạo Phái bất kỳ — ưu tiên build đã có intensity base cao để clone mang damage lớn.
