# Ngũ Hành Biến (`wuxing-shift`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | Mỗi 5 hit: linh lực đổi nguyên tố theo vòng Ngũ Hành; +10% intensity |
| T2 | Mỗi 4 hit: linh lực đổi nguyên tố theo vòng Ngũ Hành; +15% intensity |
| T3 | Mỗi 3 hit: linh lực đổi nguyên tố theo vòng Ngũ Hành; +22% intensity |

## Tương tác

Đổi element theo vòng ngũ hành (Kim → Mộc → Thuỷ → Hoả → Thổ → Kim) mỗi 3-5 hit. Element mới tác động ngay lên hit tiếp theo: tương sinh/tương khắc với đan tính theo element mới. Intensity +10-22% nhân vào `player_intensity_multiplier` mỗi lần shift. Shift là permanent trong ván cho đến khi trigger lại (không reset về gốc). Kết hợp với đan element cố định → tự nhiên xuất hiện cả tương sinh lẫn tương khắc xen kẽ.

## Build & Synergy

Roll mọi base type (prefix, element-neutral). Combo mạnh nhất với `wuxing-convert-power` (mỗi shift = 1 convert trigger → +30% intensity stacks, 10% convert lần 2 T3 → double shift). Kết hợp `vase-absorb-convert` để force element ra tương sinh đan sau khi shift ngẫu nhiên. Đạo Phái bất kỳ — ưu tiên build không phụ thuộc element cụ thể, thay vào đó route element linh hoạt.
