# Bách Lôi Tán Sát (`hundred-thunder-split`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | +18% intensity; 10% chance: linh lực split thành 3 với 50% intensity mỗi đường |
| T2 | +25% intensity; 12% chance split 3 |
| T3 | +33% intensity; 15% chance split 3; split paths có crit chance +10% |

## Tương tác

Split tạo 3 linh lực độc lập với 50% intensity mỗi cái — tổng 150% intensity so với 1 linh lực gốc. Mỗi path travel theo trajectory khác nhau (spread ~120° từ điểm split). Các path có thể bounce, proc affix, và chạm linh đan riêng lẻ. Crit chance +10% T3 trên split paths: áp dụng độc lập cho từng path — 3 paths × 10% = 3 cơ hội crit. Không có nguyên tố riêng (weight 60, không có element field) — hoạt động với linh lực bất kỳ element.

## Build & Synergy

Roll trên **drum** hoặc **bell** (AOE spread). Board rộng giúp 3 paths travel đủ xa để bounce thêm trước khi đến đan. Combo với `great-wave-spread`: mỗi path khi chạm linh khí trigger AOE — 3 paths = 3 AOE. `grassland-petal-storm` trên linh khí khác: split paths Mộc tạo thêm phụ lực. Đạo Phái bất kỳ — affix element-neutral. Cẩn thận: split paths không chia charge — mỗi path mang 50% intensity của gốc, charge tích trước split vẫn tính đủ cho từng path (charge là multiplier không chia).
