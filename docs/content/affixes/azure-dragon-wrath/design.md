# Thanh Long Nổi Giận (`azure-dragon-wrath`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | +20% intensity cho linh lực Mộc; +5% crit |
| T2 | +28% intensity cho linh lực Mộc; +8% crit |
| T3 | +38% intensity cho linh lực Mộc; +12% crit |

## Tương tác

Bonus +intensity Mộc áp vào **player.intensity_multiplier** (§7.3 Lò affix layer) — chỉ cho linh lực **Mộc** (wood). Crit chance cộng additive với `ferocious` (Hung Hãn) và các crit-chance affix khác. Linh lực Mộc tương sinh với Hoả-đan (Mộc→Hoả §7.1) → tương sinh hit gây +quality +stability (§7.2) đồng thời hưởng +intensity từ affix này. Tương khắc: Mộc khắc Thổ → phá linh khí Thổ nhưng phá linh đan Thổ. Weight 60 (uncommon).

## Build & Synergy

Roll trên mọi item base type; element `wood` → dùng Tinh Hoa Mộc để force roll. Build **Mộc** chuyên:
- `azure-thunder-frost` (Thuỷ→Mộc tương sinh): cặp đôi — Thuỷ nuôi Mộc đan, Mộc linh lực đánh mạnh hơn.
- `branch-recovery` (linh khí Cành, Mộc): heal stability khi Mộc qua → sustain + offense cùng lúc.
- Keystone **Sắc Bén** (×3 crit multi, crit chance ÷2) + crit chance từ `azure-dragon-wrath` T3 +12% → bù lại crit chance bị cắt, crit damage khổng lồ.
- Đạo Phái **Mộc** (nếu có tree node tăng Mộc intensity) là home build tự nhiên.
