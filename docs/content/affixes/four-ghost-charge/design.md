# Tứ Quỷ Xung Khí (`four-ghost-charge`)

## Tier Values

| Tier | Effect |
| --- | --- |
| T1 | +20% intensity chống boss Dị Tượng |
| T2 | +30% intensity chống boss Dị Tượng |
| T3 | +40% intensity chống boss Dị Tượng; 5% chance stun boss 0.5s |

## Tương tác

Bonus intensity chống boss Dị Tượng (T1-T8, §7.3 / §8 master spec) áp dụng tại lớp intensity multiplier — chỉ active khi linh lực chạm linh đan trong ván boss. Stun 0.5s T3 làm boss ngừng spawn tương khắc lực tạm: window an toàn để route linh lực tương sinh. Tag `anti-corruption` — boss Dị Tượng = "anomaly" category (§20).

## Build & Synergy

Roll trên bất kỳ base type nào không element-restricted — ưu tiên **talisman** hoặc **charm** (conditional trigger phù hợp boss window). Chỉ hữu dụng ở T1-T8; thay thế bằng affix khác khi push T9+. Combo với `first-strike-lethal` (hit đầu ván boss = double bonus) và `furnace-stack` (stack tích trong các ván thường, bung hết ở ván boss). Build anti-corruption stacking nên pair với affix `corruption-suppress` từ slice khác.
