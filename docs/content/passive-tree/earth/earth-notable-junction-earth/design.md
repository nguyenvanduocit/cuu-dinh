# Đạo Phái Thổ Môn (`earth-notable-junction-earth`)

## Effect

Mở cổng Đạo Phái Thổ — kết nối tới subtree Đạo Phái Thổ. +3% all defense.

## Cơ chế

Junction notable — gateway giữa earth main cluster và Đạo Phái subtree (unlock level 30). +3% all defense áp dụng global (stability, Lò Thọ, durability). Không cần đi qua đây nếu chỉ muốn earth small nodes, nhưng bắt buộc để vào Đạo Phái Thổ.

## Synergy

Hub giao lộ Hoả→Thổ (`fire-earth-bridge-1`) và Thổ→Kim (`earth-metal-bridge-1`). Nếu đi Đạo Phái Thổ (Hộ Pháp), đây là node pivot. Kết nối `earth-notable-earth-accumulate` và `earth-small-earth-purity` — mọi build Thổ sâu phải đi qua đây.
