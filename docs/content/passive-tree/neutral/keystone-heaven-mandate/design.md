# Thiên Mệnh (`keystone-heaven-mandate`)

## Effect

KEYSTONE: Xem trước 5 drop kế tiếp trong run. Trade-off: -10% drop rate Cổ vật.

## Cơ chế

Drop sequence trong pháp trận được seed trước khi run bắt đầu. Thiên Mệnh expose 5 item tiếp theo từ seed đó vào UI preview panel — player thấy loại item/element nhưng không thấy affix chi tiết. Cổ vật (Rarity `Legendary`+) nhân drop weight ×0.90 (−10% additive). Không ảnh hưởng drop weight của Common/Magic/Rare.

## Synergy

Keystone thông tin + kế hoạch: biết 5 drop tới để chủ động routing pháp trận, ưu tiên ván có yield tốt, bỏ qua ván dead-drop. Kết hợp tốt với build Atlas-control (biết drop sắp ra để chuẩn bị Đan Pháp phù hợp). −10% Cổ vật là đánh đổi đáng giá với build cần consistency hơn loot windfall. Nằm trên trục `hub-void-5` → `keystone-invincible` — lấy cả hai cùng nhau cho hybrid sustain + information.
