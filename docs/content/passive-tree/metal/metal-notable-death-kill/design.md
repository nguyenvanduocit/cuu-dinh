# Tử Sát Phong (`metal-notable-death-kill`)

## Effect

+60% crit damage Kim, -10% non-crit Kim intensity

## Cơ chế

+60% crit damage additive vào multiplier Kim (base ×2.0 → ×2.60 standalone; ×3.60 với `metal-keystone-sharpness`). −10% intensity áp lên mỗi hit Kim không crit (độc lập, không tích luỹ). Hai modifier xử lý riêng — crit path nhận +60%, non-crit path nhận −10%.

## Synergy

Node trung gian thiết yếu giữa `metal-notable-metal-light`/`metal-notable-metal-pierce` và `metal-keystone-sharpness`. Lấy Tử Sát Phong mà không lấy keystone Sắc Bén vẫn có giá: +60% crit damage standalone giúp burst linh đan nhanh. Kết hợp `metal-small-metal-crit-dmg-1` và `metal-small-metal-crit-dmg-2` (+15% mỗi node) để đẩy crit damage tổng lên ×2.0+60%+15%+15% = ×3.10 trước keystone. Path bắt buộc cho build Sắc Bén.
