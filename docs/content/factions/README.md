# `factions/` — Tong Mon (Major Factions)

> 5 factions in the world of Cuu Chau Dan Vuc.

## Design rationale

Factions represent the major power structures and philosophical alignments in the game world. Each faction has a distinct relationship to the central conflict (Tam Ma vs cultivation) and provides context for NPC motivations and quest lines.

## Entity layout

```
factions/<id>/
├── design.md   # required — faction overview, philosophy, members
└── lore.md     # optional — extended history and relationships
```
